SOFIARA — WEBSITE COMPANY PROFILE

Isi folder:
- index.html       : Halaman Home
- about.html       : Halaman About Us
- css/style.css    : Seluruh styling dan responsive layout
- js/script.js     : Interaksi menu mobile dan tahun footer
- assets/          : Folder untuk menyimpan aset gambar lokal (opsional)

CARA MENJALANKAN DI VS CODE
1. Ekstrak SOFIARA.zip.
2. Buka folder SOFIARA melalui VS Code (File > Open Folder).
3. Buka index.html di browser, atau gunakan ekstensi Live Server.
4. Klik menu Home dan About Us untuk berpindah halaman.

CATATAN
- Website menggunakan HTML, CSS, dan JavaScript terpisah.
- Gambar contoh dimuat dari Unsplash sehingga memerlukan koneksi internet.
- Ganti alamat email hello@sofiara.example dengan kontak resmi perusahaan.
- Nama produk dan deskripsi dapat disesuaikan dengan katalog SOFIARA.

VISI SOFIARA
Menjadi brand gelang emas pilihan yang dikenal karena keanggunan desain, kualitas, dan makna di balik setiap perhiasan, serta menginspirasi setiap perempuan untuk tampil percaya diri dan istimewa.

MISI SOFIARA
1. Menghadirkan koleksi gelang emas dengan desain elegan, timeless, dan mengikuti kebutuhan gaya masa kini.
2. Mengutamakan kualitas bahan, ketelitian detail, dan kenyamanan dalam setiap produk.
3. Memberikan pelayanan yang ramah, informatif, dan berorientasi pada kepuasan pelanggan.
4. Membangun hubungan jangka panjang dengan pelanggan melalui kepercayaan dan pengalaman berbelanja yang berkesan.
